 # 🌍 TravelMate Website

TravelMate is a responsive travel website designed to help users explore destinations and connect easily through different pages like Home, About, Contact, and Form.

---

## 🚀 Features

- 🏠 **Home Page** – Overview of the website and main navigation  
- ℹ️ **About Page** – Information about the website and purpose  
- 📞 **Contact Page** – Contact details for user communication  
- 📝 **Form Page** – User input form for queries or bookings  
- 📱 Fully responsive design  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  

---

## 📂 Pages Included

- index.html (Home Page)  
- about.html  
- contact.html  
- form.html  
- style.css  
- script.js  

---

## ▶️ How to Run

1. Clone or download this repository  
2. Open `index.html` in your browser  
3. Navigate through different pages  

---

## 🎯 Purpose of Project

This project is created to practice and demonstrate front-end web development skills by building a multi-page responsive website.
